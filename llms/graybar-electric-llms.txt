## API surface

Graybar publishes **no machine-readable API contract**. There is no OpenAPI, Swagger,
GraphQL SDL, AsyncAPI, Protobuf or WSDL document reachable without credentials.

- [Graybar API Portal](https://apiportal-snd.graybar.com/): Graybar's Azure API Management
  developer portal. Publicly reachable. The anonymous API catalog at
  `/developer/apis?api-version=2022-04-01-preview` returns an empty list, so no API
  definition or reference is visible without a developer account.
- [Sign in](https://apiportal-snd.graybar.com/signin): developer portal authentication.
- [Sign up](https://apiportal-snd.graybar.com/signup): developer account request.

## Integration surfaces (documented, not machine-readable)

Graybar documents system-to-system integration only in PDF fliers linked from graybar.com.

- [Electronic System Integration flier (PDF)](https://res.cloudinary.com/dngevqko7/image/upload/v1770693462/graybar-electronic-system-integration-flier.pdf):
  EDI, XML and other proprietary data formats. Transmission over VAN, FTP, SFTP, internet
  and email. Documents supported include planning schedule with release capability,
  request for quotation, customer purchase order, purchase order acknowledgement, advanced
  shipping notice, customer change order, Graybar invoice, electronic funds transfer,
  system data acknowledgement, rejection notice, and response to quote.
- [PunchOut flier (PDF)](https://res.cloudinary.com/dngevqko7/image/upload/v1770689522/graybar-punchout-flier.pdf):
  connect a procurement system to Graybar.com to browse catalog, pricing and availability
  and return a requisition. Multiple PunchOut levels supported.
- `b2b.graybar.com` resolves via CNAME to `as2.graybar.com`, an AS2 EDI transport host.
  It refuses public connections on ports 80 and 443 — it is reachable only by provisioned
  trading partners.
